# keiri — 月次支払集計テンプレート（202606〜202705）

元の Excel から、**202606〜202705 の1年分**・**1か月1シート**で集計できる形に組み直したブックを生成します。
月シートは1行＝1支払先、横に勘定科目ごとの内訳を並べ、全体シートで科目ごとの支払額が分かるようにしています。

## 成果物（`out/`）

### 1. `銀行支払明細_202606-202705.xlsx`（銀行からの支払）

| シート | 内容 |
| --- | --- |
| `科目別集計` | **全体シート。** 勘定科目 × 202606〜202705の12か月。何費にいくら払ったかが一覧できる。各月シートの合計行から自動集計。 |
| `支払先別集計` | 支払先 × 12か月。支払先ごとの月次推移。 |
| `202606`〜`202705` | **1か月1シート。1行＝1支払先、横に勘定科目ごとの内訳。** A列＝支払先、B列＝合計（左端に固定）、C列以降＝勘定科目、右端に備考、最下段に科目ごとの合計。**金額はここに入力します。** |
| `支払先マスタ` | 支払先・備考・媒体の一覧。ここに追記すると全月シートの行が増えます。 |
| `原本_みずほ銀行` / `原本_武蔵野銀行` | 元ブックのシートをそのまま保存（参照用）。 |

- 勘定科目の列は**使用頻度の高い順に左から**並べています（実績のない科目は右端）。
- 支払先の行は、**単一の勘定科目にしかならないものを科目ごとにまとめて**並べ、複数科目にまたがる支払先を最後に置いています。区分は `支払先マスタ` の「勘定科目（区分）」列に記載。
- 支払先の追加は `支払先マスタ`、勘定科目の追加は `科目別集計` のA列。どちらも12枚の月シートに自動反映されます（追加枠：支払先15行・科目3列）。
- 銀行の区別は集計に使っていません（`支払先マスタ` に参考として残してあります）。

### 2. `現金出納帳_202606-202705.xlsx`（現金）

| シート | 内容 |
| --- | --- |
| `勘定科目` | 勘定科目 × 12か月の自動集計（SUMIF）。「支払総額」と「差額（科目未入力チェック）」付き。 |
| `202606`〜`202705` | 日付／科目／摘要／支払金額。科目はドロップダウンで選択。 |

- **入金（収入）は扱いません。** 元ファイルの入金行は取り込んでいません。
- 「差額」が0以外なら、科目が未入力か表記ゆれの行があります。

## 生成方法

```bash
pip install openpyxl
python3 scripts/build_bank_payments.py input/元_銀行支払明細.xlsx out/銀行支払明細_202606-202705.xlsx
python3 scripts/build_cashbook.py     input/元_現金出納帳.xlsx   out/現金出納帳_202606-202705.xlsx
```

## 元データの扱い（銀行支払明細）

- 武蔵野銀行シートの小計行（小松車輛・アスクル等の親行）は集計せず、その内訳行だけを明細としています。支払先・媒体・備考は親行から引き継ぎます。
- 武蔵野銀行シートの74〜80行は61〜67行と同一内容の重複のため除外しています。
- 支払先名は全角/半角カッコと空白の揺れを吸収して1行にまとめています（例：アスクル(プラスロジテクス)）。
- 元ブックの `勘定科目` シートの集計値と全科目・全月で一致することを確認済みです（6月末=5,436,993／7月末=6,548,661／8月末=7,721,672／9月末=1,854,700）。
- 元ブックの月見出し（6月末〜9月末）を 202606〜202609 に対応させています。
